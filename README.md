# Web-Mahathrift

Mahathrift merupakan website jual beli barang bekas untuk kalangan mahasiswa. Website ini membantu pengguna untuk mencari dan menjual barang-barang dengan kondisi bagus dan tidak terpakai. Hal ini ditujukan untuk membantu mahasiswa yang memilih kos sebagai tempat tinggal sementara selama berkuliah. Dikarenakan tidak semua barang yang digunakan untuk keperluan kos disediakan oleh pemilik kos, sehingga mahasiswa diharuskan membeli barang-barang tersebut. 

Hadirnya website MahaThrift ini membantu untuk mengurangi sampah dan membantu mahasiswa dalam menyalurkan barang bekas yang masih layak pakai untuk dijual serta mendapatkan keuntungan dari penjualan barang tersebut. MahaThrift berfokus pada ruang lingkup mahasiswa sehingga meminimalisir adanya penipuan, lokasi yang cenderung dekat dapat disesuaikan denegan lokasi kampus dan memungkinkan penemuan produk yang relevan dan tepat sasaran.
